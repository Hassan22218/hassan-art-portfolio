# Hassan — Art & Sketchbook

A responsive, static portfolio gallery for Hassan's drawings. Built with HTML, CSS and a small amount of JavaScript; no build tools or paid services required.

## Files
- `index.html` — gallery content and page structure
- `style.css` — responsive styling
- `images/anatomical-heart-floral-study.jpg` — featured artwork

## Publish it with GitHub Pages
1. Sign in to GitHub and create a **new public repository** named `hassan-art-portfolio`.
2. Do not add a README, license or `.gitignore` during repository creation (this folder already contains a README).
3. On the new repository page choose **Add file → Upload files**.
4. Upload the contents of this folder (upload `index.html`, `style.css`, `README.md`, and the `images` folder—not the ZIP file itself).
5. Click **Commit changes**.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**; set branch to `main` and folder to `/(root)`, then click **Save**.
8. Wait for the Pages deployment to finish. The public address will be `https://YOUR-GITHUB-USERNAME.github.io/hassan-art-portfolio/` (replace the placeholder with the exact GitHub username).

## Add another artwork
1. Put a well-lit, straightened photo in `images/`, using a short filename such as `botanical-study.jpg`.
2. Copy the first artwork card in `index.html` and update its image path, alt text, title, and date/medium. Keep the filename and path identical, including capitalization.
3. Upload the changed files to the same repository. GitHub Pages will publish the update automatically after deployment.

## Before publishing
- Confirm the artwork is Hassan's original work and that he is comfortable making it public.
- Use only accurate dates and titles. The featured drawing appears signed and dated 22/12/18; confirm that this means 22 December 2018 before presenting it as a verified date.
- Add only a small selection of strong, original works. Never publish home address, phone number, school ID, or other private information.
